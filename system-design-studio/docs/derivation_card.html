System Design Derivation Card — 25 Core Formulas, In Calculation Order

Companion to System_Design_Master_Calculator.xlsx · Amazon/Flipkart-scale e-commerce · walk this order on the whiteboard
  1. DAU = MAU × DAU% / 100
  2. Peak Concurrent Users (PCU) = DAU × Peak_Concurrent% / 100
  3. Raw API RPS = (PCU × Actions/Session) / Peak_Duration_sec
  4. Peak API RPS = Raw_RPS × Safety_Buffer — the anchor number
  5. Origin-Bound Dynamic RPS = Peak_RPS × (1 − CDN_Hit%)
  6. Gateway Effective RPS/Instance = Gateway_RPS_Capacity × CPU_Util_Target%
  7. Raw Gateway Instances = ROUNDUP(Peak_RPS / Effective_RPS, 0)
  8. Total Gateway Instances = (ROUNDUP(Raw / AZs,0)+1) × AZs — N+1 per AZ
  9. Gateway Latency = Overhead_ms + SSL_Handshake_ms × SSL_Rate%
  10. Total DB QPS = Peak_RPS × Queries/API_Call
  11. Actual DB QPS (post-cache) = Read_QPS × (1−Cache_Hit%) + Write_QPS
  12. DB IOPS Required = Actual_DB_QPS × IOPS_per_Query × 2 (headroom)
  13. max_connections = Total_App_Instances × (Cores×2+1) × 1.5
  14. Hot Data Size (GB) = Write_QPS × 86400 × Retention_days × Row_KB / 1024²
  15. Redis Cluster Size = (Sessions+Catalog+HotSKU) × Overhead / Shards × Headroom
  16. Kafka MB/s = Peak_RPS × Avg_Msg_KB / 1024
  17. Kafka Internal MB/s = Kafka_MBps × Replication_Factor
  18. Partitions (adjusted) = ROUNDUP(MAX(prod-bound,cons-bound,minHA)/BrokerMultiple,0) × BrokerMultiple
  19. Brokers = MAX(MinBrokersHA, ROUNDUP(Internal_MBps/BrokerCapacity,0))
  20. P95 Latency = Blended_P50 × 1.8 — check against SLA_P95_ms
  21. DLQ Failure Rate = 1 − (Per-Attempt-Success%)^Max_Retries
  22. Reprocess Throughput = Batch_Size × Workers / Interval_min
  23. Pre-Scale Target Instances = ROUNDUP(Spike_RPS / RPS_per_Instance, 0)
  24. Load-Shed Threshold RPS = Total_Capacity × Shed_Threshold%
  25. Monthly Infra Cost = Σ(Count × $/hr × 730) + storage/egress lines
  26. Cost per 1,000 DAU = Total_Monthly_Cost / (DAU/1000) — efficiency north star
Say this first, always: "10M MAU → 2M DAU → 400k concurrent → ~3.3k raw RPS → ~7k RPS with a 2x buffer." Every number on this card traces back to that one line.
